# CleanWizard

macOS 清理工具。它使用柠檬清理的规则格式扫描磁盘，也可以直接从本机已安装的柠檬清理中提取规则库。

## 功能

| 分类 | 内容 |
| --- | --- |
| 系统垃圾 | 用户缓存、日志、保存的应用状态、邮件附件、Xcode 派生数据 |
| 应用垃圾 | 废纸篓、下载目录里的安装包、应用残留 |
| 浏览垃圾 | Safari、Chrome、Firefox 的缓存与历史 |
| 其他 | 大文件、重复文件、隐私痕迹 |

## 使用

1. 打开 CleanWizard
2. 点 **Scan**（⌘R）
3. 选择要清理的分类
4. 点 **Clean**（⌘⌫）

清理的文件先进入废纸篓。

## 规则来源

默认使用内置规则。要从柠檬清理提取规则：

- 本机需已安装并运行过柠檬清理
- 打开 **设置 → Rules → Export from Lemon**

提取过程只读取本机文件，不连接网络。

## 构建

```sh
make build   # 构建
make test    # 测试
make run     # 运行
```

推送 `v*` 标签时由 GitHub Actions 构建并发布。
